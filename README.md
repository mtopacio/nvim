# Setup

On a linux box
```bash
# for CentOS
$ wget https://github.com/neovim/neovim-releases/releases/download/v0.12.3/nvim-linux-x86_64.tar.gz
$ sudo tar -C /opt -xvf nvim-linux-x86_64.tar.gz

# add to .bashrc
export PATH="$PATH:/opt/nvim-linux-x86_64/bin"
```

Start with `nvim` and plugins should install.
